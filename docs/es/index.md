# Integración de Demo Common

Esta guía describe un catálogo Material 3 para Android API 28 o superior.
Consulta la [instalación confirmada](../../IMPORT.md) para ver las
coordenadas públicas.

| Tarea | API |
| --- | --- |
| Mostrar una bienvenida y una lista desplazable | `DemoScreen` |
| Organizar contenido personalizado en una tarjeta | `DemoCard` |
| Mostrar un encabezado con texto e icono opcionales | `CardTitle` |

Empieza con la [guía rápida](quickstart.md) y consulta los valores
predeterminados en la [referencia de API](api.md). La aplicación controla
la navegación, el estado, las traducciones y las acciones. Los componentes
leen el tema Material 3 activo y no realizan operaciones de entrada o salida.
